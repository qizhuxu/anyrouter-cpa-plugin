# 面板视觉评审记录

## 第 1 轮（独立评审，打分制）

- **评审方式**：派发一个没有本次会话历史、能看图的独立评审子 Agent，按《视觉与交互评审手册》【全新界面与改版评审】执行，主 Agent 只交证据与约束、不交源码。
- **交接物料**：6 张状态截图 + 2 倍图 + 遮字图 + 前后对比 + 两段录屏 + 动效抽帧；用户任务；设计边界（同源单文件、无外部资源、桌面为主窄屏可用、中文、额度与签到为主角、密钥不出浏览器、危险操作降权）；北极星一句；截图工具 lint 结果（本轮为空）。
- **总分：8 / 10**。总评：方向立住了、主流程全部走得通、无阻断；差距在「密度兑现」与「主角唯一」。
- **是否「重做」级别**：无。骨架是正确的台账表格，判定不需要重做区块。

### 问题清单与处理

| # | 评审指出的问题 | 处理 |
|---|---|---|
| 1 | 余额同屏重复（状态条合计与行内数字同权重），状态条六项平铺等权重、把签到与余额降成普通项 | 状态条只在「今日签到」上加重视觉（primary），账号/合计/下次签到/挑战 Cookie/数据更新全部降为次级；删除「N 个账号已读」黑话。合计保留（多账号时它才是有别于单行的汇总），但不再与行内余额争夺焦点 |
| 2 | 列宽按固定比例摊开、列间空气不均（40px 与 120px）、表头与区块标题差 8px | 列宽按内容重分配（26/14/15/27/18），行内边距 13→11px；卡片内缘统一到 14px（此前空状态是 20px），整页收敛为「卡片外 150 / 卡片内 164」两条锚线 |
| 3 | 失败态给英文原文、唯一下一步是同密钥「重试」，而「更换密钥」在右上角断成两截 | 401 直接映射为中文「管理密钥无效或已失效，请重新填写」；失败卡内给出「更换密钥」（主）＋「重试」（次）；首屏加载失败不再重复显示顶部错误条 |

小问题一并处理：未连接时不再显示整条 0 值状态条（与读失败态一致）；行内「余额」改为动词「查余额」；「停用」加描边，与纯文字的「编辑」区分开。

### 提升项与处理

| 提升 | 处理 |
|---|---|
| 精致度：余额进度条没有参照，只能靠「已用 $109.05」反推 | 进度条右侧直接标出百分比（95%），保留「已用 · 请求数 · 用户名」副行 |
| 精致度：窄屏把 5 个自明标签都列出来，一个账号撑到一屏多 | 窄屏只保留不自明的「上次签到」标签，其余四格靠值本身自证；格间距 10→8px |
| 设计感：首屏下半屏约 450px 纯空白，与「密度就是它的美感」冲突 | 收短页头边距、行内边距与折页高度（合计约 90px）；单账号时剩余的空白是该数据的真实长度，不再用占位内容填充 |
| 设计感：「下次自动签到 已关闭」用与余额同级重字 | 见问题 1：状态条只有「今日签到」保持重字，状态值一律次级 |
| 动效：抽屉末段接近匀速、遮罩与位移像两条曲线 | 抽屉与遮罩统一改用一条强缓出曲线 `cubic-bezier(.16,1,.3,1)`、同为 320ms，末段落定 |

评审对三处动效的判定：主操作 spinner、抽屉右滑＋遮罩淡入（逐帧看到左缘 1035→991、约 0.4s）、首次进入依次浮出——**都已确认做了**；余额数字滚动因 30fps 录屏只看到终值，评为「未判定」，不作为通过项记录。

### 评审「保留」项（修改时未磨掉）

1. 台账表格骨架本身（含行内「已用 · 请求数 · 用户名」副行）——不为「更像仪表盘」拆成卡片。
2. 危险操作策略：删除只在编辑抽屉、不进行内动作组。
3. 「只保存在本机浏览器，不会发给插件」这句信任说明。
4. 失败态的中文兜底文案与下一步指引。

## 评审指出的证据与交接问题（已修正）

- 录屏里「新增抽屉底部有红色删除账号」：那是 `[hidden]` 被 `.btn{display:inline-flex}` 覆盖的真 bug，评审看到的录屏是修复前那一版；现已加 `[hidden]{display:none !important}` 并重拍抽屉截图与录屏。
- ui-03 交接写 390×844，实际是 390 宽视口、整页高 885px（整页截图比视口高）。
- ui-04 交接写「签到中」，实际是**刷新余额**的忙碌态（`?state=busy` 标记的是余额按钮）；同批截图里另有真实「签到中」的帧。
- 状态参数在未连接时会被忽略（`?state=drawer`/`?state=keys` 打不开）——已修：`keys`/`drawer` 不再依赖加载成功，`edit`/`confirm`/`busy` 仍需要账号数据。

## 未验证与边界

- 编辑抽屉里的「确认删除？」二次确认、多账号下的整体忙碌与结果、接口层是否真带密钥——评审在只读源码的约束下未验证；其中接口鉴权由 `scripts/verify_live.ps1` 单独验证（无密钥 401、有密钥 200）。
- 减少动态效果（`prefers-reduced-motion`）只有 CSS 守卫与代码路径，未做媒体模拟截图。
